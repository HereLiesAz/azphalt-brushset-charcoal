# azphalt-brush-charcoal-and-chalk

Brush packages for the "charcoal-and-chalk" collection, each in its own `brushes/<slug>/` folder (manifest.json + LICENSE + assets/tip.png):

- `brushes/soft-charcoal/` — **Soft Charcoal** — A broad, soft-edged charcoal stick with heavy grain.
- `brushes/hard-chalk/` — **Hard Chalk** — A tighter, blockier chalk stick with a harder edge than soft charcoal.
- `brushes/smudge-stick/` — **Smudge Stick** — An elongated smear for dragging and blending charcoal or chalk. Rotate with angle.
- `brushes/conte-crayon/` — **Conté Crayon** — A faceted crayon tip with a cross-hatched grain. Rotate with the angle param.

`node build.js` packs every subfolder into its own `.azp`.
